## Summary

Implemented the streaming four-class classifier in
`src/analysis/cds_orth_strand_check.py`, backed by the strict shared MAF parser
and disjoint CDS interval index. The CLI validates manifest checksums, expected
assembly directives, non-empty CDS content, and MAF/GFF sequence-ID
compatibility before writing results. Output is written through temporary files
and atomically promoted only after successful completion. Synthetic tests cover
all four classes, support thresholds, ambiguous or tied strand evidence,
minus-strand coordinate conversion, malformed input, multi-trio output,
sensitivity summaries, direct CLI execution, and LF-only generated CSVs.

Six exact-assembly GFF files were acquired for `lenEdo`, `puffer`, and
`styPis`; provenance, byte size, SHA-256, accession, CDS count, and annotation
source are recorded in `config/cds_orth_strand_inputs.tsv`. The puffer B input
was corrected from the original task's unavailable `GCA_003711565.1` to the
package and MAF assembly `GCF_003711565.1`. The 11-trio availability audit is
recorded in `config/ncbi_annotation_availability.tsv`.

The complete real-data run emitted 449,420 A-CDS runs. Primary threshold-10
counts were: `lenEdo` 10,283 non-coding, 57,972 consistent, 98 contradictions,
and 2,592 insufficient; `puffer` 42,368, 175,159, 25, and 4,091; `styPis`
15,547, 135,927, 44, and 5,314. Threshold 1/10/30 sensitivity rows and raw
run evidence were generated by the CLI. Every summary row sums to its total;
raw row counts and independent class recounts match each primary summary.
Nine raw rows, one supported example per substantive class and trio, were
independently reconstructed from MAF and GFF inputs without importing the
analysis module; all coordinates, coverage counts, strand states, reasons, and
classes matched.

The combined run completed in 812.1 seconds at about 270 MB peak RSS, below the
30-minute and 1-GiB limits. The report explicitly limits interpretation to CDS
annotation and relative-strand consistency. It does not promote the output to a
manuscript result or orthology claim.
